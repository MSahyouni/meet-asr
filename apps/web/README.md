# meet-asr web client

This directory contains the Flutter-based web client for the Meet‑ASR
platform. The original project was scaffolded under the name `nabra` and
then moved up one level into `apps/web` to match the repository structure.

Use this README only for web-specific instructions; see the root
`README.md` for overall setup and API documentation.
